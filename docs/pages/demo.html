rdny demo

This demo uses only commands available in the current CLI. CI generates the actual browser-backed transcript as smoke-artifacts/docs-demo-transcript.txt, alongside screenshots, PDF, video, browser state, and logs. SourceHut uploads those artifacts for successful jobs; failed smoke logs are printed inline before the gate task fails the build. Port, pid, and browser path values are intentionally run-specific.

$ scripts/ci-smoke.sh ./result-rdny-bundled/bin/rdny
ci-smoke: PASS; artifacts in .../smoke-artifacts
$ scripts/ci-smoke-gate.sh
smoke gate: PASS
