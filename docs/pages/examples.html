rdny examples

Current workflows using the packaged rdny binary.

Start, open, inspect, screenshot, stop

export RDNY_STATE_DIR="$(mktemp -d)"
rdny start --label docs
rdny open https://example.com
rdny title
rdny text h1
rdny screenshot example.png
rdny stop

Build or run with Nix

nix run git+https://git.sr.ht/~averagechris/rdny -- --help
nix build git+https://git.sr.ht/~averagechris/rdny#rdny
./result/bin/rdny --version

Use pinned browser and ffmpeg on Linux/Nix

nix run git+https://git.sr.ht/~averagechris/rdny#rdny-bundled -- start
nix run git+https://git.sr.ht/~averagechris/rdny#rdny-bundled -- open https://example.com
nix run git+https://git.sr.ht/~averagechris/rdny#rdny-bundled -- screenshot example.png
nix run git+https://git.sr.ht/~averagechris/rdny#rdny-bundled -- stop

Connect to a browser you launched

open -na "Google Chrome" --args --remote-debugging-port=9333 --user-data-dir=/tmp/rdny-chrome
rdny --state-dir ~/.local/state/rdny-personal connect 127.0.0.1:9333
rdny --state-dir ~/.local/state/rdny-personal pages
rdny --state-dir ~/.local/state/rdny-personal stop
