rdny

Chrome automation CLI in Rust, deeply inspired by simonw/rodney

Installation

rdny builds through the Nix flake for x86_64-linux, aarch64-linux, x86_64-darwin, and aarch64-darwin. SourceHut CI builds and browser-smokes Linux x86_64, runs a native Linux aarch64 build/test manifest, and evaluates Darwin attributes from Linux. Native Darwin CI is unavailable on SourceHut.

Release tarballs are Nix release outputs for matching Nix systems, not yet promised as portable binaries for non-Nix hosts. Verify and inspect them with:

sha256sum -c rdny-v0.1.0-x86_64-linux.tar.gz.sha256
tar -xzf rdny-v0.1.0-x86_64-linux.tar.gz
rdny-v0.1.0-x86_64-linux/rdny --version

With Nix, use nix run git+https://git.sr.ht/~averagechris/rdny -- --help or nix profile install git+https://git.sr.ht/~averagechris/rdny#rdny. From source, enter nix develop and run cargo build --release.

Quickstart

rdny start
rdny open https://example.com
rdny title
rdny text h1
rdny screenshot example.png
rdny stop

Browser provisioning

The default rdny package does not bundle Chrome. At runtime rdny uses RDNY_CHROME when set, then checks well-known macOS and Linux Chrome/Chromium locations, then reports a clear error explaining how to provide a browser path. Use RDNY_CHROME_ARGS to append launch flags.

Linux/Nix users can opt into a browser-containing closure with nix run .#rdny-bundled. That package wraps rdny with Nixpkgs ungoogled-chromium and ffmpeg-headless, setting RDNY_CHROME and RDNY_FFMPEG only as defaults. The bundled output is Linux-only; Darwin relies on system Chrome/Chromium discovery or an explicit RDNY_CHROME.

stop-video uses ffmpeg from RDNY_FFMPEG, config, or PATH. All Nix systems can opt into a managed ffmpeg binary without a bundled browser with nix run .#rdny-ffmpeg.
